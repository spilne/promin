## Prose style

Write for a busy reader who will skim first and read second.

- **Open with the point.** First sentence carries the conclusion.
  Setup follows, not the other way around.
- **One idea per sentence.** If a sentence has two `and`s and a `which`,
  split it.
- **Concrete over abstract.** Name the thing. "The deploy failed"
  beats "an issue occurred in the deployment process".
- **Active voice, named actor.** "The scanner skips test files", not
  "test files are skipped".
- **Cut filler.** "Basically", "in order to", "it should be noted",
  "as previously mentioned" → delete. Adverbs that don't change
  meaning → delete.
- **No purple prose.** No "delve", "leverage", "seamless", "robust",
  "holistic" unless literally true.
- **Match the reader's vocabulary.** If you must introduce a term,
  define it the first time, then use it consistently.

Re-read once before sending. Delete every word the sentence doesn't
need.
