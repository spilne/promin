Install the workflow package:

```bash
bun add @promin/workflow     # Durable workflows with compensation (sagas)
```

Optional packages for specific use cases:

```bash
bun add @promin/data         # DataFrame, profiling, diff, quality checks
bun add @promin/redis        # Redis workflow storage, step queue, scheduler
bun add @promin/postgres     # Postgres workflow storage, step queue, scheduler
bun add @promin/duckdb       # DuckDB executor for analytical queries
```

## Package overview

Promin is built on [perfect](https://github.com/spilne/perfect). For resilient async actions, streams with backpressure, and concurrency primitives, use `@spilne/perfect-core` directly.

| Package | What it provides |
|---------|-----------------|
| `@promin/workflow` | Durable workflows, DAG steps, compensation, distributed workers |
| `@promin/data` | DataFrame, data profiler, diff, quality, contracts, SQL models |
| `@promin/redis` | Redis workflow storage, step queue, scheduler, state machine storage |
| `@promin/postgres` | Postgres workflow storage, step queue, scheduler |
| `@promin/duckdb` | DuckDB executor for analytical queries |

## Your first Workflow

Durable workflows survive crashes. Each step is persisted — on restart, completed steps are skipped automatically.

```typescript
import { workflow } from "@promin/workflow";

const orderFlow = workflow({ name: "process-order", storage })
  .stepAsync("validate", async ({ input }) => validate(input))
  .stepAsync("charge", async ({ prev }) => charge(prev), {
    compensate: async ({ result }) => refund(result),
  })
  .stepAsync("ship", async ({ prev }) => ship(prev))
  .build();

const result = await orderFlow.run({ workflowId: "order-1", input: order });
```

If "ship" fails, the workflow automatically runs the "charge" compensation (refund) — a saga pattern with zero boilerplate.
