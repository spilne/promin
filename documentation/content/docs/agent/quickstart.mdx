## Run the example

You need [Bun](https://bun.sh/), an OpenAI API key, and a checkout of this repository.

```bash
bun install
OPENAI_API_KEY=your-key bun run demo:agent
```

The [complete example](https://github.com/spilne/promin/blob/main/examples/agent-quickstart.ts) creates a `LocalAgent`, gives it a typed `currentTime` tool, and sends two messages on one thread. The second answer uses the thread history saved in `InMemoryMemoryStore`. Set `OPENAI_MODEL` to choose another compatible OpenAI model.

The workflow runner and memory store in this example are in memory. For a service that survives restarts, use [SQLite or Postgres storage](/docs/workflow/storage) and a persistent memory store.

## Explore the dashboard

```bash
bun run build:ui
ZORYA_INSECURE=1 bun run demo:server
```

Open `http://localhost:4100` to explore agent recipes, threads, traces, approvals and evals in [Zorya](/docs/agent/zorya). `ZORYA_INSECURE=1` is for local development.
